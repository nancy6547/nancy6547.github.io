発見Not every sleep is a bug.

Everyone says to delete waitForTimeout. Reading real test suites showed that about 1 in 6 is there on purpose: it gives something bad the time to happen before the test checks that it didn't. Remove it and the test passes when it should fail.

So Zeitaku reads the statement after every sleep before it touches anything. It found 196 it can safely replace and 44 it must leave alone.

zsh — zeitaku
// documenso: we must NOT navigate away
await page.waitForTimeout(1000);
await expect(page).not.toHaveURL(/\/admin\/users\/\d+$/);

$ zeitaku scan ./tests
Total waitForTimeout:   240
  replaceable:          196
  intentional:          44  (left alone)
